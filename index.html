Comment utiliser

1. Posez le téléphone à plat, écran vers le haut, sur le sol, sous votre poitrine.

2. Appuyez sur ▶ pour démarrer la session.

3. Effectuez vos pompes normalement. Chaque fois que votre poitrine touche ou effleure l'écran, une répétition est comptée et le téléphone vibre.

4. Appuyez sur ■ pour arrêter — la session est automatiquement sauvegardée.
